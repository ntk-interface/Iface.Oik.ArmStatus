## Iface.Oik.ArmStatus

Программа для мониторинга состояния АРМ, сетевых серверов «ОИК Диспетчер НТ», а также других устройств в локальной сети.

Программа может работать как внешняя задача Сервера «ОИК Диспетчер НТ» или автономно на любом удаленном компьютере.

### Запуск

При автономном запуске аргументы передаются в командной строке:

    Iface.Oik.ArmStatus сервер_динамических_данных компьютер имя_пользователя пароль

Например:

    Iface.Oik.ArmStatus TMS 10.0.0.69 admin password

При запуске в качестве внешней задачи Сервера «ОИК Диспетчер НТ» не требуется указание аргументов.

## Конфигурация обработчиков

Конфигурация каждого экземпляра обработчика хранится в отдельном файле с расширением `.json` в каталоге `configs` рядом с исполняемым файлом программы. При необходимости создайте каталог вручную.

Количество файлов не ограничено. Один и тот же обработчик может быть задействован в нескольких конфигурациях, например, для контроля нескольких устройств или АРМ.

Для конфигурации файлов используется распространенный формат [JSON](https://ru.wikipedia.org/wiki/JSON). Допускаются комментарии (`//`, `/* ... */`) и запятые в конце списков и объектов.

Структура файла:

```json
{
  "Worker": "PingWorker",
  "Options": {
    ...
  }
}
```

- `Worker` — имя обработчика из списка ниже; значение должно совпадать точно (регистр учитывается).
- `Options` — набор параметров конкретного обработчика. Имена параметров нечувствительны к регистру.
- Если файл не удалось прочитать, он содержит некорректный JSON, неизвестное имя обработчика или неверные параметры, программа завершится с ошибкой и не будет запущена. Исправьте конфигурацию и запустите программу снова.
- Изменения в конфигурации применяются после перезапуска программы.

### Общие параметры

Все обработчики поддерживают параметр:

| Параметр      | Обязательный | По умолчанию | Описание                          |
| ------------- | ------------ | ------------ | --------------------------------- |
| `WorkInterval` | нет          | `5000`       | Период опроса в миллисекундах     |

Адреса сигналов и измерений (`SetStatus`, `SetAnalog`) задаются в формате `Канал:КП:Объект`, например `24:2:2`.

## Обработчики

На данный момент доступны следующие обработчики.

### PingWorker

Определяет, доступен ли компьютер (или другое устройство) по сети с помощью ICMP (ping).

| Параметр       | Обязательный | По умолчанию | Описание                                                            |
| -------------- | ------------ | ------------ | ------------------------------------------------------------------- |
| `Host`         | да           | —            | IP-адрес или имя компьютера (устройства)                            |
| `SetStatus`    | нет\*        | —            | Адрес сигнала: `1` — устройство доступно, `0` — недоступно          |
| `SetAnalog`    | нет\*        | —            | Адрес измерения: время отклика в миллисекундах, `-1` при неудаче    |
| `Timeout`      | нет          | `500`        | Таймаут ожидания ответа в миллисекундах                             |
| `WorkInterval` | нет          | `5000`       | Период опроса в миллисекундах                                       |

\* Необходимо указать хотя бы один из параметров `SetStatus` или `SetAnalog`.

Пример:

```json
{
  "Worker": "PingWorker",
  "Options": {
    "Host": "mail.ru",
    "SetStatus": "24:2:1",
    "Timeout": 1000,
    "WorkInterval": 1000
  }
}
```

### PortWorker

Определяет, отвечает ли компьютер (или другое устройство) по заданному TCP-порту.

| Параметр       | Обязательный | По умолчанию | Описание                                                |
| -------------- | ------------ | ------------ | ------------------------------------------------------- |
| `Host`         | да           | —            | IP-адрес или имя компьютера (устройства)                |
| `Port`         | да           | —            | Номер TCP-порта                                         |
| `SetStatus`    | да           | —            | Адрес сигнала: `1` — порт отвечает, `0` — не отвечает   |
| `Timeout`      | нет          | `500`        | Таймаут подключения в миллисекундах                     |
| `WorkInterval` | нет          | `5000`       | Период опроса в миллисекундах                           |

Пример:

```json
{
  "Worker": "PortWorker",
  "Options": {
    "Host": "localhost",
    "Port": 3306,
    "SetStatus": "24:2:205",
    "Timeout": 100
  }
}
```

### TmClientWorker

Определяет, запущен ли в данный момент «Клиент ОИК Диспетчер НТ» у заданного пользователя.

| Параметр       | Обязательный | По умолчанию | Описание                                                                                       |
| -------------- | ------------ | ------------ | ---------------------------------------------------------------------------------------------- |
| `ClientName`   | да           | —            | Имя пользователя (АРМ). Сравнивается с именем и комментарием пользователя в списке клиентов    |
| `SetStatus`    | да           | —            | Адрес сигнала: `1` — клиент в сети, `0` — не в сети                                            |
| `ServerName`   | нет          | любой        | Короткое имя ТМ-сервера (например, `RBS`), если клиента нужно проверять на конкретном сервере  |
| `WorkInterval` | нет          | `5000`       | Период опроса в миллисекундах                                                                  |

Пример:

```json
{
  "Worker": "TmClientWorker",
  "Options": {
    "ClientName": "Петров",
    "SetStatus": "24:2:12"
  }
}
```

### TmServerWorker

Определяет, запущен ли в данный момент заданный сетевой сервер «ОИК Диспетчер НТ» (например, RBS).

| Параметр       | Обязательный | По умолчанию | Описание                                                  |
| -------------- | ------------ | ------------ | --------------------------------------------------------- |
| `ServerName`   | да           | —            | Короткое имя сетевого сервера (например, `RBS`)           |
| `SetStatus`    | да           | —            | Адрес сигнала: `1` — сервер запущен, `0` — не запущен     |
| `WorkInterval` | нет          | `5000`       | Период опроса в миллисекундах                             |

Пример:

```json
{
  "Worker": "TmServerWorker",
  "Options": {
    "ServerName": "RBS",
    "SetStatus": "24:2:311"
  }
}
```

## Примеры конфигураций

Готовые примеры конфигураций находятся в каталоге `sample_configs` в архиве установки:

- `ping-google-dns.json` — PingWorker с записью в сигнал и измерение;
- `ping-mail-ru.json` — PingWorker с указанием таймаута и периода опроса;
- `port-local-mysql.json` — PortWorker;
- `tmclient-petrov.json`, `tmclient-tcp-petrov.json` — TmClientWorker;
- `tmserver-rbs.json`, `tmserver-tms2.json` — TmServerWorker.

## Информация для разработчиков

Исходные коды программы являются открытыми, лицензия MIT.

Для расширения функционала можно добавить свой обработчик.

1. Добавьте класс, унаследованный от базового класса `Worker`. В конструкторе передайте в базовый класс зависимости `IOikDataApi` и `WorkerCache`:

```csharp
public class MyWorker : Worker
{
    public MyWorker(IOikDataApi api, WorkerCache cache)
        : base(api, cache) { }
}
```

2. Зарегистрируйте обработчик под нужным именем в `Program.cs`:

```csharp
services.AddKeyedTransient<Worker, MyWorker>("MyWorker");
```

После этого обработчик можно указывать в поле `Worker` файлов конфигурации.

Обязательным для реализации является метод обработки действия:

```csharp
protected override async Task DoWork(CancellationToken stoppingToken)
{
    ...
}
```

Дополнительно можно переопределить метод конфигурирования обработчика:

```csharp
public override void Configure(WorkerOptions options)
{
    ...
}
```

Если ваш обработчик мог бы пригодиться другим людям, и вы готовы бы им поделиться, мы будем рады пулл-реквесту 😀
